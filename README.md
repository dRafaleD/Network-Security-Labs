# Network-Security-Labs

# English

A beginner-friendly, hands-on network security learning journal.

The goal is to understand how networks work before moving into security analysis. Labs use small, authorized/local exercises and focus on understanding traffic rather than memorizing commands.

## Labs

- [Day 1 — Networking Fundamentals and Packet Observation](labs/01-networking-fundamentals/notes.md)
- [Day 2 — IPv4, Subnetting, ARP, Routing and DNS](labs/02-ipv4-subnetting-arp-routing-dns/notes.md)
- [Day 3 — TCP, UDP, Ports and Connection Analysis](labs/03-tcp-udp-ports-and-connections/notes.md)
- [Day 4 — ICMP, Traceroute, TTL and Network Troubleshooting](labs/04-icmp-traceroute-and-troubleshooting/notes.md)
- [Day 5 — TCP Deep Dive: Flags, States, Sequence Numbers and Retransmissions](labs/05-tcp-flags-states-sequence-analysis/notes.md)
- [Day 6 — DNS Deep Dive: Resolution, Records, Caching and Packet Analysis](labs/06-dns-resolution-records-and-analysis/notes.md)

## Learning path

Future labs will gradually cover IP addressing, subnetting, ARP, DNS, TCP/UDP, packet analysis, routing, firewalls, segmentation, and defensive network monitoring.

## Safety

Perform active network-security exercises only on systems and networks you own or have explicit permission to test.
